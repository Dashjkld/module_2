# Расчет заработка за смену

## Назначение программы

Консольная программа для расчета заработка работника за одну смену с учетом обычных и сверхурочных часов.

## Вариант

Вариант 4

## Используемые темы Python

- Ввод и вывод данных (input(), print()).
- Переменные и типы данных (str, float, int).
- Арифметические операции.
- Условные конструкции (if, elif, else).
- Логические операторы (and, or).
- Циклы (for, while).
- Функции.
- Форматирование строк с помощью f-строк.
- Методы обработки строк (.strip(), .lower(), .capitalize().

## Инструкция по запуску

1. Открыть проект.
2. Открыть файл `src/main.py`.
3. Запустить программу.
4. Ввести имя работника, почасовую ставку и продолжительность смены.

## Глобальные константы

- NORMAL_HOURS = 8 — количество часов, оплачиваемых по обычной ставке.
- OVERTIME_RATE = 1.5 — коэффициент оплаты сверхурочных часов.
- MAX_HOURS = 12 — максимально допустимая продолжительность смены.

## Локальные переменные

- name — имя работника.
- rate— почасовая ставка.
- shift_duration — продолжительность смены.
- overtime_hours — количество сверхурочных часов.
- overtime_payment — оплата сверхурочной части.
- total_salary — общий заработок.
- category — категория смены.

Переменные используются для хранения введённых данных и результатов вычислений. Результаты предыдущих расчётов не сохраняются.
